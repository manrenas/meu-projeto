# meu-projeto

git init 
- iniciar novo projeto com o git 

gitt add <nome-arquivo>/.
- add os arquivos estão prontos para serem commirados

git commit -m "menssagem commit"
- commit os arquivos no historico

git log
- mostra os ultimos commits, log de alterações

git status
- como está o estado das nossas ramificações

git diff
- que mostra o que foi alterado
- o que tem de alteração na nossa ramificação

git merge
- merge de ramificações, mescla ramificações

git branch 
- mostra a branch atual

git checkout <nome-branch>
- muda pra essa branch

git branch -b <nome-branch>
- criar nova branch a partir da branch atual que estamos

git remote add <nome> <url>
- adiciona um novo repositorio remoto

git push <nome> <nome-branch>
- manda nossas alterações locais para o repositorio remoto, para cada branch

git pull <nome> <nome-branch>
- pega as alterações do repositorio remoto, e joga pra nossa maquina

git fetch
- atualiza o novo historico local de acordo com o nosso historico salvo la no repositorio
- faz uma sincronização do local com o remoto
